# 2026-10-14

## 改造：精炼炉取消自动布局，改为「场景摆放位置 + 按名字顺序逐级出现」

需求：主场景 Wolrd 里手动摆了若干精炼炉（Furnace、Furnace2…）；
取消原先的精炼炉自动布局，位置按场景里摆的来；升级时按炉子名字顺序逐个出现。

### 改前的两处「自动布局」
1. `wolrd.gd::_place_furnace()`：每帧不参与，但开局把 `$Furnace` 强制挪到地图正中心
   （`MAP_SIZE/2` → 世界坐标 **(4128, 2336)**）。
2. `wolrd.gd::_spawn_furnace()`（「扩建精炼炉」升级时）：遍历全地图格子，
   选离所有已有炉子最远的一格，自动散布新炉子。

### 关键约束（改动时必须记住）
- 机器人和掉落物都靠 **`get_nodes_in_group("furnace")` + 距离**找炉子
  （`robot.gd::_find_nearest_furnace`、`dropped_item.gd`）。
  ⇒ 未解锁的炉子不能只是 `visible=false`，**必须退出分组**，否则机器人会跑去没出现的炉子卸货。
- `@onready var furnace = $Furnace` 被 `_setup_camera()`（相机初始目标）和 `_spawn_robot()`（机器人出生点）使用，
  所以 `_collect_placed_furnaces()` 必须排在它们**之前**。

### 改动清单
- `script/refining_furnace.gd`
  - 新增 `_is_active` / `is_active()` / `set_active(bool)`：
    停用时 `visible=false`、`input_pickable=false`、`set_process(false)`、**`remove_from_group("furnace")`**，
    并清空 `_smelt_timer`；启用时反向恢复。
  - `_process` 开头加 `if not _is_active: return` 兜底。
- `script/wolrd.gd`
  - 删除 `_place_furnace()`、`_spawn_furnace()`、`FURNACE_EDGE_MARGIN`、`FURNACE_SCENE` 预加载。
  - 新增 `_collect_placed_furnaces()`：从 "furnace" 分组收集 → `sort_custom(_furnace_order_cmp)`
    → 全部 `set_active(false)` → 只启用第 1 个，`_reveal_furnace_index = 1`。
  - 排序用「名字结尾数字」自然排序（`_name_tail_number`）：Furnace(0) < Furnace2 < Furnace3…
    数字相同再按名字比。
  - `_reveal_next_furnace()`：`add_furnace` 升级回调改为启用下一个（不再生成新节点）。
  - 自动同步科技上限：`GameManager.set_tech_max_level("add_furnace", maxi(1, 炉子数 - 1))`
    ⇒ 放 N 个炉子 = 开局 1 个 + 升级 N-1 级。（`maxi(1, …)` 保证 `unlock_more_ores` 的前置可满足）
- `GameManager.gd`
  - 新增 `_tech_max_level_overrides` + `set_tech_max_level()`；
    `get_tech_max_level()` 优先读覆盖值。
- `script/tech_tree_ui.gd`
  - `_make_tech_row` 里的 `tech.get("max_level", 1)` 改为 `GameManager.get_tech_max_level(tech_id)`，
    否则科技树 UI 看不到运行时覆盖。
- `scene/wolrd.tscn`
  - 给 `Furnace` 节点补上 `position = Vector2(4128, 2336)`（= 原来代码居中的位置），
    这样取消自动居中后视觉不变，用户可以再自己拖走。

### 验证（Godot 4.7.2 headless，副本 `F:/tmpgodot/check4`）
写临时 `test_reveal.gd/tscn`：加载 wolrd，直接改 `tech_levels`/`lab_stage` 后连续 `unlock_tech("add_furnace")`。

- 3 级后 `can_unlock_tech` 为 false，Lv 3/3
